# P-66（不合入）与 dhu 关键路径（2026-10-15）

## P-66：bN 选择矩阵 MMAC 的 C 初值从 -0.0 改为 +0（`examples/kda/p66_bn_zero_c.py`）
- **理由**：h 永远不会是 -0，所以 +0 初值的结果也精确。h0 = +0；upd 是从 +0 开始累加的 MMAC 和，不会是 -0；RNE 下两数相加得 -0，要求两个加数都是 -0。改用 +0，想省掉 P-63d 物化 -0.0 所需的 v_mov。
- **逐位门禁**：10/10，含 gate-extreme，外加 FI=3。
- **A/B**（bw7，基线为含 P-65 的生产版）：重算递推 16K/12 为 0.976，64K/12 为 0.984；算子 0.9975 / 0.9988。**否决**。原因还没分析，推测是调度或寄存器分配跟着变了。
