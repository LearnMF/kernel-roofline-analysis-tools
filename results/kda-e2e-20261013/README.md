# Megatron K3 端到端复测（2026-10-13，bw52，同一时段）

**配置**：与 `results/kda-xplat-a800-20261010/megatron_e2e.md` 完全相同。
- 脚本：`k3_matrix_bw52.sh`；
- 模型：K3 L4 切片（3 层 KDA + 1 层 MLA），16 个 expert，4 张卡，EP4，12 次迭代；
- 采集：rank0 用 profiler 采第 10–11 步，KDA kernel 时间按 kernel 名分类求和；
- 跳过的配置：8K/TP2 和 32K/TP4，这两组在 64 GB 上 OOM（10-10 已确认）。

**版本**：
- ours：hip_kda G2 生产版 7ff2524（含 P-43/P-48/P-49），`KDA_G2_KEEP_STATE=0`，不用显存换速度；
- 对照组：FLA 0.5.2，带 DCU 的 autotune 剪枝。

## 说明

- **环境可比**：BW 上 FLA 默认与 10-10 相比只差 ±1.6%，说明两次测量环境可比。
- **改善的来源**：相对 10-10，ours 快了 11.5–18%，是第 12–13 轮各项合入的累计效果。
- **对比 A800 的口径**：A800 的数据是 10-10 在另一台机器（PCIe 互连）上测的，属于跨机器、跨时段的比较。在相同配置下，实际训练中 ours 的 KDA kernel 时间已经比 A800 FLA 默认少 7–12%（10-10 时是多 8%）。
