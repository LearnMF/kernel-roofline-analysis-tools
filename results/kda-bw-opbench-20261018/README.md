# BW1000 同卡对 FLA 的算子级复测（P-88 生产版，2026-10-18）

- **用途**：更新飞书 KDA 文档“算子级：单层 KDA 前向+反向”表中的“最新”三列。
- **环境**：bw46 HCU4，容器 `tanbo_kda_b46`，镜像为 megatron-0.18.2 dtk2604，与飞书文档相同。当时只有这张卡的显存是空的，其余卡的显存被其他用户占着。
- **被测对象**：
  - 树为 `/opt/kda_env/g2_r5`，即 P-88 生产版；
  - FLA 为 `/opt/kda_env/fla` 下的 0.5.2 版本，带 DCU 补丁；
  - 运行时按 `fla_prune_ns4` 裁剪 FLA 的 autotune 配置。
- **方法**：
  - 脚本为 `tests/megatron/kda_op_bench_tp.py`，arms 取 fla、fla_nr、g2。三种实现在同一进程里用同一份输入交替运行，用 CUDA event 计时，取 7 次的中位数；
  - 每个形态跑 2 个独立进程，结果取平均（`opbench46.sh`）；原始数据在 `opbench46_p88.jsonl`，汇总在 `summary.json`。
- **结果**（前向+反向）：

| 比较对象 | 16 个形态的范围 | 几何平均 |
|---|---:|---:|
| 对 FLA 默认 | 1.87–2.34 倍 | 2.06 |
| 对 FLA 最快配置 | 1.68–2.11 倍 | 1.85 |
| 只看前向，对 FLA 默认 | 1.47–2.36 倍 | — |
| ours 相对首版（飞书表中的原值）的提速 | 1.35–1.54 倍 | 1.43 |

- **复测质量**：
  - 两个进程之间相差不超过 1.5%；
  - FLA 两档的重测值与飞书表中的原值相差 −0.8%～+7.8%，其中 64K/TP1 偏差最大。
- **显存**：
  - 单层峰值为 FLA 默认的 0.80 倍。
  - 前向留给反向的数据，测试程序报告的是 H ≤ 48 时 1544 B、H = 96 时 1032 B。这个程序自己持有作为叶子的 q/k，所以多算了 qn/kn 的 512 B。按 K3 的口径，H ≤ 48 时为 1032 B（等于 FLA 默认），H = 96 时为 520 B。
