# KDA 算子三平台对比：BW1000 + hip_kda G2（当前生产版）对比 A800 / H20 上的 FLA 0.5.2（2026-10-17）

## 口径
- **我们**：bw52，生产版 `g2_opt` `931f9e3`，即本次会话结束时的状态（P-77b、P-82/82b、P-83/83b、P-84b/84c、P-85、P-87）。
  - 用 `examples/kda/round_vs_a800.sh` 测：每个形态 5 个进程，加地址抖动（R20），设备时间 = hipprof 统计的一次前向+反向 kernel 时间之和。
  - 本次会话开始时的生产版（P-65，`g2_opt_bak_p77b`）在**同一会话里与当前版逐进程交替测量**，所以“gain”一列是 A/B 对比，不是跨会话比较。
  - 墙钟时间 = 用 event 包住一次前向+反向，在单卡上顺序跑 3 个进程。
- **A800 / H20**：FLA 0.5.2，torch 2.10.0+cu128，triton 3.6.0，两边软件栈完全相同。指标是 CUPTI 统计的 kernel 时间之和，以及墙钟时间，每个形态 3 个进程。
  - “def”是 FLA 默认配置（保存 1032 B/token·head）；“fast”是 `disable_recompute`（保存 3336 B/token·head）。
  - **这次没有重测 FLA**：A800 节点（a800-1/2）经 bw-zz 已经连不上；H20（h20-7）的 8 张卡正被其他团队的 sglang 服务占用（每卡 127 GB），我们的容器 `tanbo_kda_h20` 也已经停了。所以沿用之前测的数据：A800 来自 2026-10-11/12 的 `../kda-xplat-a800-20261010/raw/op16/nv.jsonl`，H20 来自 2026-10-12 的 `../kda-xplat-h20-20261012/raw/h20.jsonl`。FLA 的代码、版本和硬件都没变，这些数据依然有效。
- **调用参数**与 Kimi K3 相同：bf16 q/k/v [1,T,H,128]，门控在 kernel 内激活，sigmoid 之后的 fp32 beta，qk 的 l2norm 在 kernel 内完成，cu_seqlens = [0, T]。
- **比值**一律是“对方耗时 / 我们”，**大于 1 表示我们更快**。
- **显存**（前向保存给反向的字节，K3 口径）：
  - 我们：TP8/TP4/TP2 为 1032 B/token·head（saved-h，与 FLA 默认相同）；TP1 为 520 B（不保存 h）。
  - FLA 默认 1032 B，FLA fast 3336 B。

## 结果

完整表格见 `tables.md`（由 `examples/kda/xplat3_report.py` 生成）。

**设备时间（16 个形态）**：
- 对 **A800 FLA 默认**：**16/16 个形态都更快**，比值 1.03–1.43，几何平均 **1.16**。
- 对 A800 FLA fast：TP8/TP4/TP2 的 16K–64K 全部更快（1.01–1.27）；TP1 和部分 8K 形态是 0.94–0.96。16 个形态几何平均 1.05。
- 对 **H20 FLA 默认**：0.71–0.99，16 个形态几何平均 **0.81**；9 个重点形态（16K–64K，TP>1）几何平均 **0.87**（2026-10-12 时是 0.76）。64K/TP8 已基本持平（0.99）。
- 对 H20 FLA fast：0.64–0.87，9 个重点形态几何平均 0.77。
- **本次会话带来的提速**（同会话 A/B）：1.03–1.12；TP8 为 1.09–1.12，TP2 为 1.06–1.11，TP1 为 1.03–1.06。

**墙钟时间**：
- 对 A800 默认：15/16 更快（8K/TP1 为 0.95）；TP8 时是 1.32–1.56，因为 FLA 每次调用的 host 侧开销大。
- 对 H20 默认：0.65–0.93。

**按带宽归一化**（实测 HBM 读带宽：BW1000 1339、A800 1771、H20 3821 GB/s）：每单位带宽完成的工作量，我们是 A800 FLA 默认的 1.36–1.89 倍、H20 FLA 默认的 2.0–2.8 倍。

**要在设备时间上追平 H20 FLA 默认**，9 个重点形态还需提速 1.08–1.24 倍（几何平均约 1.16 倍；2026-10-12 时要 1.32 倍）；TP1 需要约 1.39–1.41 倍。H20 的实测带宽是 BW1000 的 2.85 倍，差距的根源是硬件带宽。在逐位一致、不改算法的约束下，剩余空间见 `../kda-ceiling-cards-20261016-p82` 第 6 节。
