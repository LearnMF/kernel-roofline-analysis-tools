# flash-train（a1e0e35）对 hip_kda（P-88）：算子级同进程对比（2026-10-20）

- **用途**：在把 KDA 提交到 GitHub 版 flash-train 之前，确认 flash-train 现有实现与 hip_kda 最佳实现之间的性能差距。
- **被测对象**：
  - flash-train：`ft_kdag2_git` HEAD `a1e0e35`。wheel 的 md5 为 `2f8d40890e78`，与 bw7 上已验证的 ft_site_r29 相同。
  - hip_kda：`g2_opt` 的 P-88 版本。
- **环境**：bw52 HCU3，容器 `tanbo_mega_bw52`。
- **方法**：
  - 脚本为 `kda_op_bench_tp.py`，arms 取 g2、ft；两者在同一进程里用同一份输入交替运行，CUDA event 取 7 次的中位数，每个形态跑 2 个进程；
  - 设置 `BENCH_CKPT=1`，加测 Megatron 全层重算的形式：reentrant checkpoint，即不带梯度跑一次前向，再在反向里重算前向，然后做反向。

| 形态 | 普通前向+反向 g2 / ft（ms） | ft/g2 | 重算形式一步 g2 / ft（ms） | ft/g2 |
|---|---:|---:|---:|---:|
| 8K/H12 | 3.33 / 3.61 | 1.084 | 4.37 / 4.49 | 1.028 |
| 8K/H48 | 12.67 / 13.60 | 1.073 | 16.17 / 16.31 | 1.008 |
| 16K/H12 | 6.24 / 6.83 | 1.094 | 7.94 / 8.35 | 1.052 |
| 16K/H24 | 12.55 / 13.67 | 1.089 | 16.12 / 16.48 | 1.022 |
| 16K/H48 | 23.51 / 27.04 | 1.150 | 30.07 / 32.09 | 1.067 |
| 16K/H96 | 47.96 / 51.61 | 1.076 | 58.58 / 64.37 | 1.099 |
| 32K/H12 | 11.59 / 13.18 | 1.137 | 14.78 / 15.91 | 1.076 |
| 64K/H48 | 91.67 / 101.44 | 1.107 | 114.36 / 120.80 | 1.056 |
| **几何平均** | | **1.101** | | **1.051** |

**结论**：flash-train 现有实现比 hip_kda 最佳实现慢，普通训练形式慢 7–15%，Megatron 全层重算形式慢 1–10%；在重算形式下，峰值显存也略高（+2–4%）。

原因：
- 按此前的决定 C（不改 flash-train 的公开 ABI），P-77b（前向保存 qn/kn，反向去掉 l2n_apply）和 P-82/P-87（前向保存 h，反向不再重算递推）都没有移植进 flash-train。
- flash-train 在重算形式下走的是 keep-state 路线：状态缓冲固定为每 token·head 1024 B。hip_kda 在 H ≤ 48 时改走 saved-h 路线：每 token·head 512 B，而且更快。
