# 在 P-87/P-88 生产版上重测的账目和上限卡（2026-10-17）

- **原始数据**：`raw/`，在 bw52 上用 `collect52.sh` 采集。16K/12 用 HCU3（快卡），16K/48 用 HCU4。**HCU4 比其他卡慢约 10%**，所以 16K/48 的绝对时间偏大，但各 kernel 下限的比例仍然可用。
- **账目**（`raw/*/ledger.json`）：
  - 16K/12：实测显存字节 4748 MB，是算法必需量的 5.86 倍；接口字节 4115 MB。
  - 16K/48：19876 MB，6.13 倍。
- **上限卡**（`cards.json`）：
  - 16K/12：实际 5770 µs，各 kernel 下限之和 4870 µs（差 15.6%），接口下限之和 3352 µs。
  - 16K/48：差 18.6%。
  - 详细分析见 `../kda-xplat-3way-20261017/h20_gap_analysis.md` 第 3 节。
